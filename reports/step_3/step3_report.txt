Train/Validation/Test Splitting

To ensure reproducible evaluation and balanced learning, the unified dataset (12,159 utterances) was divided into training, validation and test subsets. Because the merged corpus is not perfectly balanced across the four target emotions, a stratified sampling strategy was applied. This guarantees that the proportional distribution of emotions is preserved in each subset, preventing under-representation of specific classes during parameter tuning and final testing.

We used a 70/15/15 split ratio, consistent with common practice in speech-emotion recognition. First, the data were separated into a training set (70 percent) and a temporary set (30 percent). The temporary set was then evenly divided into validation (15 percent) and test (15 percent), again using stratification based on the unified emotion labels.

The resulting distribution is shown in Table X. All emotions appear with comparable proportions in each subset, demonstrating that the stratification procedure was successful. These splits were fixed and used consistently throughout feature extraction, model training, hyperparameter tuning and evaluation.
